# Mazu Adventure 交付報告

專案已完成本機可運作版本，並依上傳的《Unit 05 Religions 宗教.pptx》逐頁核對全部 17 頁。網站尚未對外發布。

## 已完成且測試通過

- 六個獨立學習模組：19 個單字的翻卡／配對／拼字、完整五段閱讀、完整十段 Ethan／Laura 對話、文化藝廊、五段原文聽力、原教材三題寫作訂正。
- 每個模組另有五題可訂正重試的小測驗，共 30 題，不計入冒險分數。
- 六關冒險、60 題正式題庫，每關 5 題教材改編與 5 題延伸；每局抽 30 題，兩類各 15 題。選題、選項及句子詞塊保留答案身分後隨機排序。
- 原創廟宇與文化 SVG、固定探險角色、六站側向地圖、可跳過的故事／轉場、不同角色動畫及減少動態效果支援。
- 三顆愛心、錯題恢復、30 題首次答案紀錄、最終關 4/5 過關、重新選題與無限重試、首次分數凍結、成績拆解、徽章、答對／錯題檢視與重玩。
- Web Speech 語音控制、聲線切換、停止與重播、速度調整、語音替代文字；原創合成音樂／音效與靜音、音量控制。
- 無帳號、無後端、無 API 金鑰；學生資料只留在本頁記憶體，不寫入 localStorage 或資料庫。
- 鎖定依賴重裝、production build、16 項單元測試與 12 項瀏覽器測試通過；同一組瀏覽器測試亦於 production build 執行通過。

題庫驗證詳見 `question-bank-validation.md`，來源覆蓋見 `source-coverage.md`，測試證據與限制見 `verification.md`。

## 已完成，但未人工實測的部分

語音、音樂與音效已有實作及程式層驗證，但未實際聆聽學校設備的喇叭輸出。英文聲線依作業系統與瀏覽器提供，無可用語音時使用文字替代。尚未進行真實班級試教或獨立文化專家審閱。

教材「世界三大宗教活動」的排名未獨立查證，介面已標示為教材說法；第 4 頁英中人數敘述不一致，保留原文並註明，不以該人數出題。開放式寫作提供參考答案與自我檢核，不聲稱可以自動評斷所有英文句子的文法。
